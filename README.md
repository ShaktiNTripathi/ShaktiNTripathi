## 🟩 Show **private** work on your public green graph

GitHub shows **“131 contributions in the last year”** when only **public** activity is counted. Client work on **private** repos stays hidden until you turn this on:

| Step | Action |
|------|--------|
| **1** | Open **[Profile settings → Contributions & activity](https://github.com/settings/profile#contributions-activity)** |
| **2** | ✅ Turn on **“Include private contributions on my profile”** |
| **3** | Save — private commits appear as **green squares** (repo names stay private) |
| **4** | Hard refresh your profile: **Ctrl + F5** |

> After enabling, your public profile graph can show **much more** activity if you commit regularly to private repos. The cards below use `count_private=true` so README stats align when GitHub exposes that data.
